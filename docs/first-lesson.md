# Первый шаг в настоящем проекте

Проект: ИИ-ассистент поддержки и обработки заказов с базой знаний и действиями.
Сначала пишем надёжную логику на Python, затем добавим API, хранение данных и ИИ.

1. Открой `src/app/services/orders.py` в дереве файлов кабинета.
2. Перенеси свою функцию `get_order_status(order)`, которую уже разбирали с наставником.
3. Нажми Ctrl+S. В строке состояния должно появиться «Сохранено на диск».
4. Нажми «Отправить код наставнику». Название файла уйдёт вместе с кодом.

Проверь понимание без запуска: какой результат ожидаешь для заказа со статусом,
для заказа без ключа status и для заказа с пустым status?

Следующий шаг — самостоятельно записать эти случаи в тесты. Не переходи к нему,
пока не разобрались с функцией. Каркас FastAPI — техническая заготовка, а не уже
освоенная тобой тема.

# Support Assistant

[![Python](https://img.shields.io/badge/Python-3.11-3776AB?logo=python&logoColor=white)](https://www.python.org/)
[![FastAPI](https://img.shields.io/badge/FastAPI-0.135-009688?logo=fastapi&logoColor=white)](https://fastapi.tiangolo.com/)
[![Tests](https://github.com/StaliGiw/support-assistant/actions/workflows/ci.yml/badge.svg)](https://github.com/StaliGiw/support-assistant/actions/workflows/ci.yml)

Учебный backend-проект ИИ-ассистента для поддержки клиентов и обработки
заказов. Ассистент будет находить ответы в базе знаний, проверять состояние
заказов и выполнять разрешённые действия.

Проект развивается небольшими завершёнными итерациями. История Git показывает
путь от функций на Python к API, базе данных и интеграции с LLM.

## Использование ИИ при разработке

Функциональный код проекта автор пишет самостоятельно в процессе обучения.
ИИ используется как наставник и средство контроля: объясняет необходимые темы,
ставит небольшие задачи, проверяет результат и помогает автору самостоятельно
найти ошибки, не подменяя процесс написания кода готовыми решениями.

При запуске проекта ИИ помог подготовить технический каркас, тестовую
инфраструктуру и оформление репозитория. Все новые функции автор разбирает,
пишет и запускает сам, чтобы уметь объяснить каждое принятое решение.

## Что уже реализовано

- получение статуса заказа с безопасным значением по умолчанию;
- проверка возможности отмены заказа;
- регистронезависимый поиск текста в базе знаний;
- каркас FastAPI и служебный маршрут `GET /health`;
- автоматические тесты бизнес-логики и API;
- CI-проверка тестов через GitHub Actions.

## Архитектура

```text
src/app/
├── api/           # HTTP-маршруты FastAPI
├── schemas/       # модели запросов и ответов
├── services/      # бизнес-логика заказов и базы знаний
└── main.py        # точка входа приложения

tests/             # автоматические тесты
docs/              # учебные материалы и задания
```

## Запуск

Требуется Python 3.11 или новее.

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -e ".[dev]"
.venv\Scripts\python.exe -m uvicorn app.main:app --reload
```

После запуска:

- API: http://127.0.0.1:8000
- интерактивная документация: http://127.0.0.1:8000/docs
- проверка состояния: http://127.0.0.1:8000/health

## Тестирование

```powershell
.venv\Scripts\python.exe -m pytest
```

Тесты также запускаются автоматически при каждом push и pull request.

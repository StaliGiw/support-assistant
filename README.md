# Support Assistant

Учебный проект: помощник поддержки, который будет находить ответы в базе знаний
и выполнять разрешённые действия с заказами.

**Текущий этап:** каркас FastAPI и проверка `/health`. Логика заказов, база знаний,
база данных и LLM ещё не реализованы. Учебные функции пишет автор; ИИ помогает
объяснениями и проверкой, а также подготовил технический каркас.

## Структура

- `src/app/main.py` — точка входа FastAPI.
- `src/app/api/` — HTTP-маршруты.
- `src/app/services/` — правила приложения, начинаем с `orders.py`.
- `src/app/schemas/` — будущие модели данных.
- `tests/` — тесты.
- `docs/` — задания и решения по устройству проекта.

## Запуск в Windows

Из этой папки:

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -e ".[dev]"
.venv\Scripts\python.exe -m uvicorn app.main:app --reload
```

Документация API: http://127.0.0.1:8000/docs

```powershell
.venv\Scripts\python.exe -m pytest
```

Если окружение уже подготовлено, повторять установку не нужно.
Папку можно открыть в PyCharm или VS Code: интерпретатор — `.venv/Scripts/python.exe`.

## Работа из кабинета

Кабинет располагается на два уровня выше и запускается отдельно. В редакторе
выбирай файл из дерева, сохраняй Ctrl+S и отправляй код на проверку. Ctrl+S пишет
именно в выбранный файл этой папки. Скачивание копии — отдельная кнопка ↓.
